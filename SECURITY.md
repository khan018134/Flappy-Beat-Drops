# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. If GitHub's private vulnerability reporting is enabled for this repository, use it to contact the maintainer privately. Otherwise, contact the repository owner through their GitHub profile and include a description of the issue, its impact, and steps to reproduce it.

Please allow the maintainer a reasonable opportunity to investigate and address a report before sharing it publicly. Do not include real user data or secrets in a report.

## Scope

Flappy Beat Drop is a static browser game and does not provide user accounts or a server-side application. Reports about the website, install flow, service worker, or unsafe handling of browser data are welcome.
